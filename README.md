# NPA Risk Prediction

> **Domain:** Banking

## Overview

Predictive default probability model for retail lending incorporating bureau history, delinquencies, and application attributes. Outputs converted to risk-tiered scorecards for approval/decline decisions.

## Skills & Technologies

- Credit Risk Modelling
- Feature Engineering
- Logistic Regression
- Gradient Boosting
- Scorecard Development
